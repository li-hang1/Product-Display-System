# 二维码商品展示系统（木耳批发店专用）

给线下木耳批发店使用的商品展示系统：每个样品袋贴一张二维码，顾客用**微信扫一扫**或手机浏览器扫码，直接打开该商品的手机展示页（大图、产地等级、特点介绍、品质图集、批发价、一键拨号、微信咨询）。

店家在电脑浏览器打开管理后台，即可新增商品、自动生成二维码、下载 / 打印二维码。

- 数据存储：JSON 文件（`data/products.json`），**无需安装数据库**
- 技术栈：Node.js + Express + 原生 HTML/CSS/JS（无复杂前端框架，好维护）
- 系统已自带便携版 Node.js（`tools/node`），**没有安装 Node 也能双击运行**

## 二、在 Windows 电脑上运行

### 方式一：双击启动（最简单，推荐）

1. 双击项目里的 **`启动.bat`**
   - 第一次运行会自动安装依赖（约 1~3 分钟，只需一次）
   - 之后自动启动服务并打开浏览器
2. 浏览器会打开 `http://localhost:3000/admin/index.html`
3. 输入管理密码登录：**`admin123`**（默认，建议登录后在「系统设置」里修改）

> 如果 Windows 弹出"防火墙"提示，勾选"专用网络"和"公用网络"并点允许，否则手机无法访问。

### 方式二：命令行运行（已安装官方 Node.js 时）

到 https://nodejs.org 下载 **LTS 版**安装（一路下一步），然后：

```bat
cd /d C:\Users\20386\code\one_project\qrcode-shop
npm install
npm start
```

启动成功后控制台会显示（示例）：

```
====================================================
  二维码商品展示系统 启动成功
----------------------------------------------------
  电脑访问后台:  http://localhost:3000/admin/index.html
  手机测试地址:  http://192.168.x.x:3000   (手机需与电脑同一Wi-Fi)
  默认管理密码:  admin123
====================================================
```

> 端口被占用时，可换端口启动：`set PORT=8080 && node server.js`，然后访问 `http://localhost:8080`。

## 三、完整测试流程（对应验收 6 步）

1. **电脑启动项目**：双击 `启动.bat`
2. **浏览器打开后台**：`http://localhost:3000/admin/index.html`，密码 `admin123`
   （首次启动自带一个演示商品 MD001「东北精选秋耳」，可直接用，也可删掉）
3. **创建测试商品**：点「＋ 新增商品」，填写编号（如 `MD002`）、名称、产地、等级、特点、价格、电话、微信号，可传商品主图和品质展示图 → 保存
4. **自动生成二维码**：商品列表点该商品的「二维码」按钮，弹窗中可看到二维码图片和它指向的链接（`http://地址/product/商品编号`）
5. **手机扫描**：先按下面第四节配好"访问地址"，再用手机扫码
6. **手机出现商品展示页**：顶部大图 → 名称 → 产地/等级/规格 → 批发价格 → 产品特点 → 品质展示图集（可点开放大）→ 底部「电话咨询」（直接拨号）和「微信咨询」（显示微信二维码/微信号可复制）→ 页面最底部是商家名称

## 四、手机连接电脑测试（关键步骤！）

手机扫码要能打开页面，二维码里必须是**手机也能访问的地址**。按以下步骤操作：

1. **手机和电脑连同一个 Wi-Fi**（最常见失败原因就是连了不同的网络）

2. **查看电脑的局域网 IP**（两种方法任选）：
   - 登录后台 →「系统设置」→ 页面会自动列出推荐地址（如 `http://192.168.1.100:3000`），点击即可填入
   - 或者：按 `Win + R` 输入 `cmd` 回车，运行 `ipconfig`，找"无线局域网适配器 WLAN"里的 `IPv4 地址`，例如 `192.168.1.100`

3. **配置访问地址**：后台 →「系统设置」→「访问地址」填入 `http://你的IP:3000`（如 `http://192.168.1.100:3000`）→ 保存

4. **Windows 防火墙放行**（如果手机打不开再做这一步）：
   - 方法 A：在 cmd 里运行（需管理员）：
     ```bat
     netsh advfirewall firewall add rule name="QRShop 3000" dir=in action=allow protocol=TCP localport=3000
     ```
   - 方法 B：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 找到 Node.js 勾选"专用/公用"；首次启动时弹窗直接点"允许"也行
   - 方法 C（临时验证）：先关闭防火墙试一下，能通说明就是防火墙问题，再按 A/B 精确放行

5. **验证**：手机浏览器手动输入 `http://192.168.1.100:3000/product/MD001`，能打开商品页说明通了

6. **扫码测试**：后台 → 商品「二维码」→ 用微信扫一扫 / 手机相机扫码 → 打开商品展示页

常见问题：
- **微信提示"非微信官方网页"**：点"继续访问"即可，属正常提示；介意的话部署到服务器+域名后会好很多
- **手机打不开**：依次检查是否同一 Wi-Fi → 防火墙 → 访问地址是否配置正确 → 电脑 IP 是否变化（换网络后 IP 会变，重新设置）
- **二维码扫出来是 localhost**：说明「系统设置 → 访问地址」没配或配错，后台二维码弹窗里也会出现黄色警告提示

## 五、日常使用流程

1. 商品到货，拍照（主图 1 张 + 细节图几张）
2. 后台「新增商品」：填编号（如 MD003）、名称、产地、等级、特点、价格、电话、微信号，传图，保存
3. 列表点「二维码」→「打印二维码」，打印贴到样品袋上（打印页可选每页 1/2/4/6/9/12 张标签）
4. 顾客扫码看货，想买就打电话或加微信
5. 改价格 / 改介绍：后台「编辑」，保存后二维码**不用重新打印**（二维码指向编号，内容实时更新）

## 六、以后部署到服务器（让任何网络的手机都能扫码）

本地局域网方案只适合"手机和电脑同一 Wi-Fi"。要让顾客用流量也能打开，需要部署到公网服务器：

### 1. 准备
- 一台云服务器（阿里云 / 腾讯云等，最低配 2核2G 足够）
- 一个域名（国内服务器必须做 **ICP 备案**，否则微信里打不开；香港/海外服务器可免备案但速度稍慢）

### 2. 服务器上安装 Node.js（≥16）

```bash
# CentOS:  curl -fsSL https://rpm.nodesource.com/setup_20.x | bash - && yum install -y nodejs
# Ubuntu:  curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt install -y nodejs
node -v
```

### 3. 上传项目并启动

```bash
# 方式一：scp 上传（Windows cmd 里执行，或用 WinSCP/宝塔面板上传）
scp -r qrcode-shop root@你的服务器IP:/opt/

# 方式二：git（先把项目推到 gitee/github，服务器上 clone）

# 服务器上：
cd /opt/qrcode-shop
npm install --production
npm install -g pm2
pm2 start server.js --name qrcode-shop
pm2 save && pm2 startup     # 开机自启
```

### 4. Nginx 反向代理 + HTTPS

```nginx
server {
    listen 80;
    server_name shop.example.com;      # 换成你的域名
    client_max_body_size 20m;          # 允许上传图片
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

HTTPS 证书（推荐，微信内打开更顺畅）：

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d shop.example.com
```

### 5. 修改系统设置

后台 →「系统设置」→「访问地址」改为 `https://shop.example.com` → 保存。
然后到商品列表**重新下载/打印二维码**（二维码内容已变成正式域名）。

### 6. 数据备份

所有数据就是两个目录，定期复制即可：
- `data/`（商品数据、设置）
- `uploads/`（商品图片）

## 七、常见问题 FAQ

| 问题 | 解决办法 |
| --- | --- |
| 忘记管理密码 | 用记事本打开 `data/settings.json`，把 `password` 改回 `"admin123"`，重启服务 |
| 端口 3000 被占用 | `set PORT=8080 && node server.js`，之后地址都改用 8080 |
| 手机打不开页面 | 见第四节常见问题 |
| 图片上传失败 | 单张不超过 10MB，格式限 jpg/png/webp/gif |
| 想改商家名称 | 后台 → 系统设置 → 商家名称 |
| 删除商品后二维码 | 扫码会显示"商品不存在或已下架"，属正常 |
| 数据在哪 / 怎么搬家 | `data/` + `uploads/` 两个文件夹复制到新电脑即可 |
